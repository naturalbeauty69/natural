SITEMAP DOMAIN FIX

Problem found:
The generated Next.js sitemap at /sitemap.xml was using the old domain
https://naturalbeautyclinic.com.np while the live site is
https://naturalbeauty.com.np.

That caused Google Search Console:
"URL not allowed — This URL is not allowed for a Sitemap at this location."

Replace only:
app/sitemap.ts

No Supabase SQL changes are needed.

After deployment:
1. Open https://naturalbeauty.com.np/sitemap.xml
2. Confirm all <loc> URLs start with https://naturalbeauty.com.np
3. In Google Search Console, open Sitemaps.
4. Remove the old sitemap submission if it is duplicated, then submit:
   https://naturalbeauty.com.np/sitemap.xml
5. Wait for Google to reprocess it.

Do not change the database or robots.txt for this fix.
