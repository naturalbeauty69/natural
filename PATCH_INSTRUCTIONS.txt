Natural Beauty Academy — Account, Mobile, Blog Cover & Notification Patch
=========================================================================

Replace ONLY these website files:
  app/academy/resources/page.tsx
  components/academy/AcademyResourceList.tsx
  components/BlogCard.tsx

What changed
------------
1. Academy page now has visible Login and Create account buttons.
2. Academy filters are desktop-friendly but no longer sticky/large on mobile.
   Mobile uses a compact expandable Filter control.
3. Academy query now includes access_level and the course name relation so the
   filters and access badges have the data they need.
4. Blog cards now use an existing local library image as a category-based fallback
   when a blog cover_image_url is empty. No external stock-image dependency was added.
5. The public/ private Supabase access model is not changed.

Authentication
--------------
The current project already contains /login, /register and /pending-approval pages.
This patch surfaces those links from the public Academy page; it does not change
Supabase Auth or user roles.

Notifications
-------------
The main schema already creates in-app notifications for appointments, messages,
and reviews. The optional SQL file in this patch adds an in-app notification for
new course applications.

Run the optional SQL ONCE only after confirming that public.notifications and
public.course_applications exist.

Important
---------
This SQL sends an in-app notification to the existing admin Notification Center.
It does not send external email because no email provider configuration is present
in the source reviewed for this patch.

Deployment
----------
1. Replace the three website files above in GitHub.
2. Commit and push.
3. Wait for Cloudflare to deploy.
4. Open /academy/resources in desktop and mobile.
5. Test Login and Create account buttons.
6. Test Academy filters and confirm the filter panel no longer covers the list on mobile.
7. Test a blog with no cover_image_url to confirm a fallback image appears.
8. Optionally run the SQL file once and submit a test course application to confirm
   an admin in-app notification appears.

Do not rerun the existing full Academy migration just for this patch.
