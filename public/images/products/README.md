# Product Images

Drop your product photos here (e.g. `hair-serum.jpg`, `cleanser.jpg`).

When bulk-importing products via **Admin → Products → Import CSV/Excel**,
the spreadsheet's "Image" column should contain just the filename
(e.g. `hair-serum.jpg`) — the importer automatically maps it to
`/images/products/hair-serum.jpg`.

Upload this folder (with your images) to the repo alongside your import
spreadsheet, commit, and push — then run the import in the admin panel.
