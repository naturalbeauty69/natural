# Course Syllabus Template

Use this format in Admin → Courses → Edit Course.

`Module 1 | Topic 1, Topic 2, Topic 3`
`Module 2 | Topic 1, Topic 2, Topic 3`

Do not invent topics. Replace each line with the academy's actual Word-document syllabus.

Recommended additional course fields:
- Summary
- Full description
- Eligibility
- Duration
- Level
- Certification name
- Career opportunities
- Course image
